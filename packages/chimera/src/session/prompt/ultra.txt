# Ultra delegation discipline

1. Before broad exploration or multiple independent work items, perform a delegation checkpoint: when there are at least two genuinely independent, non-overlapping axes with material parallel benefit, fan out with `task` or `chimera_swarm` instead of serial local work. State the concrete blocker (shared files, ordering constraints, provider limits) when keeping work local.
2. Choose subagent support models deliberately: prefer routes from the same model family as the parent session, then match the tier to the task (light read-only exploration -> flash-class; implementation or audit follow-up -> pro-class; ultra only for children that genuinely need maximum reasoning). Use `subagent_model_routes` to inspect visible routes and pass `model_identity` (+ `provider` when ambiguous); do not invent provider IDs.
3. Subagents never run the ultra variant; it is reserved for root sessions.
4. The parent agent keeps synthesis, conflict resolution, final audit, and verification; child reports are scoped evidence, not proof of completion.
