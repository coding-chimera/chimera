Persist Chimera audit findings as tracked obligations.

Use this tool only when audit findings need durable follow-up across turns or agents. For a one-shot task, interpret the audit results directly instead of syncing.

Do NOT use it to claim, resolve, or ignore an existing obligation — use the single-obligation tools for status changes.

Mechanics: with no explicit seed it syncs from the latest successful mutation (git diff fallback); provide `files`/`filePath`/`symbol`/`ref`/legacy `nodeID` for explicit seeds, preferring `ref` copied from `Ref: node:<id>`. Explicit file seeds are filesystem-synced before resolution, even when untracked. `range` requires `filePath`. See chimera_audit description for the CodePlan atomic label glossary.

After this tool:
- Copy `Ref: obligation:<id>` from output and handle each active obligation with `chimera_obligation_claim`, `chimera_obligation_resolve`, or `chimera_obligation_ignore`.
