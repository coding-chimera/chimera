Run the default Chimera propagation audit for the latest successful tool mutation.

Use this tool after successful `edit`, `write`, or `apply_patch` mutations before claiming a code-change task is complete.

Do NOT pass file paths to this tool — it audits the latest mutation automatically; use `chimera_audit` for explicit files, symbols, or node ids. One audit per mutation batch is enough — do not also run chimera_audit on the same files afterwards; chimera_audit is for explicit seeds from other sources (external patches, a specific symbol).

Mechanics: findings are structural evidence, not commands or tracked obligations. Provenance files missing graph records are filesystem-synced before classification. Set `refresh` to false only when current graph state is known sufficient.

See chimera_audit description for the CodePlan atomic label glossary.

Use `chimera_obligations_sync` only for tracked follow-up.
