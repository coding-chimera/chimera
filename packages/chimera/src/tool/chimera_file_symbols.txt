List indexed symbols for a known file or source range.

Use this tool when you already know the file path and need CodeGraph nodes inside that file, or nodes intersecting a specific range.

Do NOT use it for open-ended search — use `chimera_search` for query-based graph search and `grep` for raw source text.

Mechanics: explicit `filePath` values are filesystem-synced before resolution, even when untracked by git. `range` requires `filePath` and narrows to intersecting symbols.
- Output enrichment: symbol hits append up to 3 lines of source definition excerpt each, and the host file lists up to 2 companion test files as a `Tests: <path>` line (total added output is budget-capped at 2KB).

`projectPath`: optional path to another initialized Chimera project (or its subdirectory) for strictly read-only cross-project queries; never initializes or writes there. In cross-project mode `filePath` resolves against the target's indexed records and is not filesystem-synced. See `chimera_status` for full cross-project rules.

After this tool:
- Copy `Ref: node:<id>` from output when a later Chimera tool accepts `ref` or `refs`; use `chimera_impact` or `chimera_audit` when the listed symbols may propagate behavior.
