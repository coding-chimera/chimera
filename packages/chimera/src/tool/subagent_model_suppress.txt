Persist one explicit future-hide instruction for subagent routing. ONLY call this tool after the user explicitly says a provider or exact route should no longer be shown or used in future. Ordinary task failure, fallback, resume, unique route resolution, or a task_model allow/reject/once/always decision does not count; in particular, one task_model rejection must never become durable suppression.

This is a root-session-only mutation tool. It validates the exact provider, model identity, and provider/model route against the current visible live Provider catalog under effective agent and session task_model rules. A provider target suppresses that provider across identities; a route target suppresses only the exact identity route. Suppression is reversible only through a later explicit user restoration instruction handled by subagent_model_prefer. Suppression is route-level: it hides every variant of that model, including `ultra`; there is no per-variant granularity.

The dedicated subagent_model_suppress permission is requested first. Only after it succeeds is task_model requested for the final exact provider/model route; suppression never bypasses concrete task_model authorization. Do not use ordinary task_model permission as a chooser or learning signal. Never include, persist, or output provider credentials, headers, keys, endpoints, internal options, or other sensitive provider fields.
