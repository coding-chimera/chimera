Retrieve one captured Chimera oracle result by typed ref or legacy id.

Use this tool when a specific oracle ref/id is known (prefer `ref` copied from `Ref: oracle:<id>` output) and you need the raw captured shell or LSP evidence plus the mutation provenance linked to that result.

Returns recorded evidence only; it never reruns commands, classifies them, or creates obligations. Payload: structured `oracle`, `linkWindow`, and `linkedChanges` data — `oracle.payload.shell` carries the command, cwd, exit code, output, and truncation state; `oracle.payload.lsp` carries the diagnostics. `maxOutputChars` bounds included shell output.
