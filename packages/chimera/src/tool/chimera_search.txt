Search Chimera's CodeGraph-backed graph index by query.

Use this tool when you need graph evidence for symbol names, qualified names, signatures, or CodeGraph-indexed text.

Do NOT use it for arbitrary source-code literals, regex searches, or match counting — use `grep` for raw source text and `glob` for filename patterns.

Query phrasing:
- Multi-word queries are OR-of-prefix: each word matches as a prefix and results are unioned; "session prompt" finds `session*` OR `prompt*`. Each free-text term keeps a guaranteed quota of result slots. With free-text terms, output ends with a `terms: <term>(<hits>) ... · <N> candidates before limit` fact line.
- Prefer separate concept words ("system prompt") for broad discovery; use a glued compound ("SystemPrompt") only when searching a real compound identifier. Real compounds also match by parts, so "prompt" finds `buildSystemPrompt`.
- Field filters compose with the text: `kind:function`, `lang:typescript` (alias `language:`), `path:src/api`, `name:auth`. Example: `kind:method name:send transport`.
- Output enrichment: the first 5 symbol hits append up to 3 lines of source definition excerpt each, and each hit's host file lists up to 2 companion test files as a `Tests: <path>` line (total added output is budget-capped at 4KB).
- Top 3 definition hits also carry a `Refs(<N>):` block of call/reference sites with trimmed source lines (file-level imports tagged `(file-level)`). One search call usually replaces grep + triage + a follow-up impact/read.

`projectPath`: optional path to another initialized Chimera project (or its subdirectory) for strictly read-only cross-project queries; never initializes or writes there. See `chimera_status` for full cross-project rules. An uninitialized graph returns the structured unavailable state with zero results — call `chimera_init_graph` first.

After this tool:
- Copy `Ref: node:<id>` when a later tool accepts `ref`/`refs`; use `chimera_impact` for caller impact, and `read` only after graph evidence points to concrete files.
