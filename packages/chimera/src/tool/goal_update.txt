Update the status of this session's goal.

Set status to `complete` only when the objective has actually been achieved and no required work remains. Set status to `blocked` only when the same blocking condition has repeated and no progress path remains. Set status to `paused` only at the user's explicit request. Set status to `active` only to resume a paused goal at the user's explicit request. You cannot clear budget_limited with this tool. When marking a budgeted goal complete, report the final token usage from the tool result to the user.

Transitions allowed: active -> complete, blocked, or paused; paused -> active (resume); any status -> complete. Resuming a blocked goal is user-side only: the user can run `/goal resume` in the session, which re-arms auto-continuation with a fresh unproductive-streak audit — this tool cannot do it. A budget_limited goal cannot be resumed at all (the budget takes priority over resume); the user must create a new goal with a fresh budget (`/goal <objective>` or goal_create). The tool fails when no goal exists. Any status other than active stops auto-continuation; while a goal is active, turns that end without any tool call count as unproductive and 3 consecutive unproductive continuations mark the goal blocked automatically.
