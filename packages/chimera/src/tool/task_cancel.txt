Cancel a background task, a background `chimera_swarm` worker, or a background `orchestrate` program started by this session, interrupting its run and any subagents it launched.

Use this when:
- First-wins fan-out: you launched several independent background probes (task with background=true) to answer one question; the first one that returns enough information makes the remaining probes obsolete. Cancel the rest instead of letting them keep running and consuming the background_concurrent budget.
- A background task is no longer needed: its goal became obsolete, you already have the answer, or continuing would just waste work and overlap files/topics you are about to touch.
- The user asks you to stop a background task you started.
- A background `chimera_swarm` worker (dispatched with `background: true`) is no longer needed: cancel it individually with the task_id from the start receipt or its completion notice. That id is the worker's child session id. There is no batch cancel — cancel each unneeded worker one at a time.
- A background `orchestrate` program (dispatched with `background: true`) is no longer needed: cancel it with the `job_id` from the start receipt. That id is the program-level job; cancelling it interrupts the program and cancels every subagent it is running.

Rules:
- You can only cancel tasks you started yourself: a task whose parent session is not this session is rejected with an error. Each task belongs to the session that launched it.
- Calling it on a task that already finished (completed, cancelled, or error) is not an error: it returns a short terminal-state snapshot and does nothing.
- Cancelling a running task also interrupts the task's child run, and cancellation propagates recursively to any further background tasks that child had launched. Cancelling a background `orchestrate` program cascades to all of its running subagents.
- Pass the exact task_id from the tool receipt, the completion notice, or the `## Background Tasks` section (the job/session id). A task_id that does not exist is reported as an error.
- One action per call: pass exactly one task_id. Cancel tasks one at a time.

This tool only cancels background-mode tasks, background swarm workers, and background orchestrate programs. It does not start, pause, resume, or alter tasks, and calling it never affects the current run.
